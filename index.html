EXECUTIVE BRIEFING

Bypassing the Perimeter: The Kerberoasting Threat

Problem & Root Cause: Under standard Active Directory Kerberos protocol mechanics, the Key Distribution Center (KDC) must return an encrypted Service Ticket (TGS) to any authenticated domain user who requests an SPN. The ticket is encrypted using the password hash of the service account.

LEGACY vs gMSA ARCHITECTURAL COMPARISON
Legacy Service Account:
  • Human-generated static password
  • Weak RC4 cipher
  • Manual rotation risk / downtime
gMSA Upgrade (Machine Accounts):
  • 128-character machine keys
  • Enforced AES-256 encryption
  • Automated 30-day AD key rotation

Business Impact: Prevents $56M catastrophic ransomware breaches resulting from compromised service accounts while complying with SOC 2 CC6.3 & NIST SP 800-53 controls.

SECURITY BLUEPRINT

OWASP 2026 Security Mitigation Playbook

1. Broken Access Control (#1 Risk)

Every API endpoint must verify ownership: SELECT * FROM tickets WHERE id = ? AND user_id = current_user. Disable all default database/cloud accounts.

2. Cryptographic Failures

Enable Disk Encryption on Cloud SQL/RDS. Enforce TLS 1.3 only. Secrets managed via HashiCorp Vault / AWS Secrets Manager.

3. Injection Prevention

Mandatory parameterized queries. Deploy Web Application Firewall (WAF) with SQLi rules enabled.

4. CI/CD Vulnerability Scanning

Trivy and Snyk integrated into GitHub Actions. Pipeline breaks automatically on Critical vulnerabilities.
